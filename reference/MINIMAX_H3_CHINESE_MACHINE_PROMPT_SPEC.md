# MiniMax H3 中文执行六段式提示词规约 (Chinese Execution Prompt Spec)

本规约定义了专供国内创作者直接复制送入 MiniMax H3（海螺视频）进行 AI 视频渲染的**中文执行六段式标准契约**。它将英文底层执行契约完全本土化为结构严密的中文语法，彻底解决“仅使用自然语言审稿版导致大模型丢失参考图、出现背景污染或口型漂移”的缺陷。

---

## 一、 六段式核心架构与解析优先级

中文执行提示词必须严格包含以下 6 个顶层字段，按顺序书写，严禁乱序或缺漏：

```text
主体定义：
...明确声明上传资产与镜头实体的严格绑定映射...

任务摘要：
...声明任务类型（如：[参考生成]）与本片段核心剧情...

保留分析：
...针对每个主体，逐一明确指令：继承哪些特征，丢弃/排除哪些干扰...

镜头详述：
...按时间轴 [镜头 N] 顺序推进的景别、运镜、物理动作与台词容器...

环境音响：
...总结本镜头画面内真实发出的物理拟音、脚步声与环境底噪...

非剧情音乐：
...声明非现场配乐要求（如“无配乐。”或指定乐器节奏）...
```

---

## 二、 实体槽位标签对照系统 (Subject Labels)

为了与操作员上传面板和底层的 Attention 机制完全对齐，中文执行版采用标准实体标签：

| 中文标签 | 对应英文标签 | 适用资产类型与规则 | 实战写法示例 |
| :--- | :--- | :--- | :--- |
| **`<主体 N>`** | `<Subject N>` | 可复用人物身份、服装造型、特定道具或风格参考。 | `<主体 1>：周曜，18岁男高中生，东亚面孔，短发，身穿蓝白运动校服。` |
| **`<图片 N>`** | `<Picture N>` | 精确首帧（I2VA）、尾帧（L2VA）或分镜关键帧锚点。 | `<图片 1>：红色本田小踏板机车，复古做旧外壳。` |
| **`<视频 N>`** | `<Video N>` | 垫片、运动轨迹参考或延展源视频。 | `<视频 1>：机车甩尾漂移物理运动轨迹参考。` |
| **`<音频 N>`** | `<Audio N>` | 音色参考、呼吸语速或真实配音。 | `<音频 1>：沈听晚音色与语速节奏参考（对应上传音频 1）。` |
| **`(S1)`, `(S2)`** | `(S1)`, `(S2)` | 画面内发音人物顺序编号，用于口型绑定。 | `(S1) 指代周曜，(S2) 指代沈听晚。` |

## 三、 任务摘要与保留分析词汇表 (Retention Policy)

### 3.1 任务摘要标识符
首行必须使用方括号声明生成模式：
- `[参考生成]`（多主体外观/环境参考，Ref2VA）
- `[首帧锚定生成]`（从指定第一帧向前延展，I2VA）
- `[首尾帧过渡生成]`（在首帧与尾帧之间插值生成，FL2VA）
- `[尾帧对齐生成]`（向指定最后帧平滑收敛，L2VA）

### 3.2 保留分析四大法定策略词（彻底防穿帮）
在 `保留分析：` 中，必须针对每个定义的主体指明处理策略：

1. **`reference`（参考继承）**：
   - 继承面部五官、骨相、发型发色与服装款式；
   - **必须显式排除**：参考图原有的白底影棚背景、旧光线或静态姿势，动作与环境完全由本场景重新渲染。
2. **`weak_reference`（弱参考 / 风格迁移）**：
   - 仅借鉴色彩倾向、颗粒质感、摄影对比度或光线柔和度，绝不继承参考图里的人物或物品。
3. **`fully_copy`（完全复刻）**：
   - 100% 像素级对齐（常用于固定道具或精确首帧）。
4. **`attribute_transfer`（属性迁移）**：
   - 将参考图的特定纹理（如真皮做旧感、金属氧化锈迹）赋予当前实体。

## 四、 镜头详述与台词口型规范 (Detailed Description & Dialogue)

### 4.1 镜头时间轴标记
- 第一个镜头标记为 `[镜头 1]`，后面跟随初始时长（例如 `0.0—3.5秒`）；
- 后续切镜必须带有明确的起止毫秒时间戳：
  `[镜头 2] 00:03.500 起，至 00:08.000 切点。`

### 4.2 台词专用口型容器（防对错口型与文字浮屏）
中文执行版中，角色的台词必须使用 `<d>[中文] ... </d>` 专用口型容器包裹：
- **前置发音人声明**：说话前必须明确写出发音人编号与调动方式：
  `(S2) 使用 <音频 1> 音色参考，微微挑眉，音调轻快直球地说：`
- **对白容器包裹**：
  `<d>[中文]谁让你车速飙到六十码？我来自2024年，但我也怕死好不好！</d>`
- **画外音口型保护**：若为内心独白或旁白，必须紧随声明：
  `（(S1) 此时紧闭嘴唇，面部无任何下颌开合咀嚼动作，声音纯为画外音）。`

## 五、 实战标准范例 (H3 单元中文执行版完整样张)

```text
主体定义：
<主体 1>：周曜，18岁中国男生，东亚清爽五官，利落短发，身穿千禧年蓝白拼接运动校服，脚踩黑色帆布鞋。
<主体 2>：沈听晚，18岁中国女生，东亚清冷素颜，及肩黑发微散，身穿现代极简防风风衣，头戴白色机车半盔。
<图片 1>：红色本田复古小踏板机车，金属外壳带有轻微岁月划痕。
<音频 1>：沈听晚音色与语速节奏参考（对应上传音频 1，时长 10.0 秒）。

任务摘要：
[参考生成] 盛夏烈日下汕头八角亭前，红色机车急刹停定，沈听晚摘下悬浮白头盔挑衅回怼周曜，周曜怒意化为慌乱。

保留分析：
<主体 1>：reference，保留角色五官骨相与千禧年校服特征，骑车姿态与扭头动作由本场景全新生成。
<主体 2>：reference，保留角色清冷素颜与风衣质感，摘盔动作与悬浮效果由本场景全新生成。
<图片 1>：reference，保留机车复古红色漆面与结构比例，石板路滑行制动由本场景生成。
<音频 1>：reference，继承音色明亮度、咬字共鸣与语速节奏，排除原音频台词与背景杂音。

镜头详述：
[镜头 1] 0.0—3.5秒。中景正打。沈听晚双手利落地解开卡扣摘下头上的白色半盔，乌黑长发微散在肩后，额前碎发随风拂动。她将白色半盔推至身前，半盔竟在半空诡异悬浮轻微晃动，泛着淡淡的时空虚光。
[镜头 2] 00:03.500至00:08.000。特写镜头。沈听晚清亮的眼眸直视前方单脚撑地的 (S1)。她使用 <音频 1> 的音色与语速节奏参考，秀气眉峰微挑，带着理直气壮的狡黠笑意说：
<d>[中文]谁让你车速飙到六十码？我来自2024年，但我也怕死好不好！</d>
[镜头 3] 00:08.000至00:12.000。双人反打过肩镜头。听到这句话，(S1) 咬紧的牙关微微松开，怒意瞬间化为一丝不知所措的慌乱，深褐色双眸剧烈闪烁，右耳垂泛起明显红晕，视线在沈听晚与悬浮头盔之间反复游移。

环境音响：
机车排气管在空气中留下的低沉怠速轰鸣声，盛夏树梢蝉鸣，微风吹拂衣角声，头盔塑料卡扣脆响。

非剧情音乐：
无配乐。
```
