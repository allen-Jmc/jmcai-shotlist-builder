# MiniMax H3 跨片段剪辑连续性

本文件专门处理多个独立 H3 生成片段在剪辑点上的连续性。单段提示词结构正确、人物一致或结尾写了“保持稳定”，都不能证明相邻片段可剪。必须把整个场次当成一条镜头序列，并把每一对相邻片段当成一个需要共同设计、共同验收的剪辑边界。

## 一、先规划整场镜头阶梯，再切 H3 片段

在写任何独立片段提示词前，先建立 `SCENE_SHOT_LADDER`。按最终播放顺序列出整场所有内部镜头，而不是每进入一个 H3 片段就重新从中景、推近或正面人物开始。

相邻同场 `H3_UNIT` 还必须执行“尾态复写”：把上一单元的稳定 `exit_state` 中实际可见的空间、姿态、朝向、视线、服装、道具和环境声完整写入下一单元 `opening_state`。禁止只写“承接上一段”“保持连续”或依赖上一条提示词。

每镜至少记录：

- `shot_id` 与所属 `h3_unit_id`；
- 景别、裁切位置、人物画面占比；
- 焦段感、机位高度、角度、主轴和屏幕方向；
- 主要注意力目标与这一镜新增的信息；
- 入镜动作阶段、出镜动作阶段和道具状态；
- 剪入触发与剪出触发；
- 是否承载对白、画外音或纯环境声。

整场镜头阶梯必须形成有意图的距离、角度和注意力变化。禁止因为换了独立生成片段，就把镜头语言无理由重置为“正面中景慢推”。

## 二、每一对相邻片段必须建立边界台账

在写边界两侧任何一段提示词前，同时建立一个 `CLIP_BOUNDARY_LEDGER`。每对相邻独立片段恰好一条，不能只写上一段的 `exit_state` 或下一段的 `opening_state`。

必填字段：

| 字段 | 内容 |
| --- | --- |
| `boundary_id` | 例如 `H3-01__H3-02` |
| `from_clip` / `to_clip` | 出片段与入片段 |
| `editorial_purpose` | 这一刀改变什么信息、视角或情绪 |
| `boundary_strategy` | 从下节四种策略中选择且只能选择一种 |
| `cut_trigger` | 动作、视线、原文短语、声音、信息揭示或场景转换 |
| `outgoing_last_frame` | 景别/裁切、焦段感、机位/主轴、人物占比与屏幕位置、眼线和头身方向、道具持有/位置/状态、动作阶段、相机运动向量、背景/光位、嘴部、情绪、现场声 |
| `incoming_first_frame` | 与上一项完全相同的字段集合 |
| `continuity_invariants` | 两侧必须完全一致的事实 |
| `deliberate_differences` | 为了剪辑而主动改变的景别、轴线、注意目标或构图 |
| `requested_duration` | 提示词请求时长 |
| `expected_or_observed_platform_duration` | 平台支持或实际输出时长；不得假定等于请求值 |
| `head_handle` / `tail_handle` | 可剪的稳定头尾余量 |
| `prompt_evidence_en` / `prompt_evidence_zh` | 两侧提示词中落实本边界的具体句子或镜头时码 |

如果任一字段未知，先调整分镜或明确风险；不得把“承接上一段”当作证据。

## 三、四种合法边界策略

每一对相邻独立片段只能选择一种主要策略：

1. `exact_match_continuation`：两侧精确延续同一机位、景别、裁切、姿势、动作阶段、运动方向和道具状态。适合动作匹配、步态延续或同一表演的续段。若没有首尾帧锚点或可验证的动作相位，独立生成风险高。
2. `contrast_cut`：主动切换注意目标，并至少改变“景别、轴线/角度、裁切/前景关系”中的两项。适合人物到道具、人物到视线目标、远景到明确近景或反应镜头。
3. `neutral_bridge`：用环境、道具、视线目标、脚步、灯光、雨面、门、屏幕等中性桥接镜头，重置轴线并隐藏独立生成漂移。
4. `scene_transition`：地点、时间或现实层级明确改变；新的建立镜头与声音关系必须写明。

没有合法策略，边界即为构建失败。

## 四、跳切风险硬判定

满足以下任一条件时，不得标为“连续性通过”：

- 同一人物、同一轴线或同一注意目标、相邻或近似景别，但人物大小、姿势或画面位置发生未经匹配的变化；
- 同轴同主体的画面占比变化约 10%–35%，却没有明确的动作匹配、时间跳跃或用户批准的跳切意图；
- 上一段结尾与下一段开头“很像但不完全一样”，例如近景缩回中近景、正面略换角度、目光或表情重置；
- 下一段开头已经完成了观众没有看见的状态变化，例如手机从脸前直接变到身侧、伞由打开变关闭、人物突然换了朝向；
- 相机运动方向或速度在切口处无理由反转、停止或重新起步；
- 两侧都以同一人物正面慢推作为开头/结尾，且没有新增信息。

修复优先级：精确首尾帧/续接工作流 → 改为动作匹配 → 改成 `contrast_cut` → 插入 `neutral_bridge` → 重新生成。不要用一句“保持连续”掩盖几何冲突。

## 五、画外音的口型风险必须靠构图降低

`says in an off-screen voiceover` 和“visible lips remain completely closed”仍是必要协议，但只写文字约束不够。模型可能因为正面人物与声音同时存在而自动生成口型。

长画外音期间遵守：

- 不让同一可见人物以正面、居中、口部清晰可读的中近景或近景承载整段画外音；
- 优先采用背面、过肩、嘴部被伞沿/前景遮挡的侧面、手部或道具、人物视线目标、环境切片；
- 若必须看脸，只在画外音前后或极短的不可读口型侧面出现；
- 先设计安全画面，再补充“嘴唇闭合”文字约束，不能反过来；
- 生成后只要画外音期间出现可辨认口型，即判定为需要重剪、遮挡或重生，而不是提示词通过。

## 六、平台时长与剪辑余量

必须区分：

- `requested_duration`：HTML 与提示词的计划时长；
- `supported_duration`：平台实际可选择的离散时长；
- `observed_duration`：下载成片的真实时长。

独立片段尽量预留 0.5 秒稳定头部余量和 0.8–1.0 秒稳定尾部余量。尾部余量内禁止开始新动作、继续推镜或让表情再次变化。若完整台词、标点停顿、动作和余量无法同时容纳，应延长或重分片段；不得挤占尾部余量后仍宣称“可剪”。平台输出多出的帧也不能自动算作余量，只有内容稳定时才算。

## 七、生成后边界验收

用户提供生成视频时，必须做成片验收，不能只复读提示词：

1. 探测实际时长、帧率、尺寸和内部切点；
2. 对每个边界检查上一段最后 0.5–0.75 秒与下一段最前 0.5–0.75 秒的逐帧或接触表；
3. 对比主体大小、景别、裁切、主轴、屏幕位置、视线、动作阶段、道具状态、灯光锚点、天气、口型、情绪和声音；
4. 按以下等级给结论：`edit_safe`、`trim_or_crop_repairable`、`insert_or_transition_repairable`、`regeneration_required`；
5. 把实际结果反馈到 `CLIP_BOUNDARY_LEDGER`，再决定是否修改提示词。

结构 linter、字段完整和台词逐字一致都不能代替成片边界验收。只有生成后画面与声音同时通过，才能称为“剪辑连续性通过”。

## 八、交付前硬性检查

- `SCENE_SHOT_LADDER` 覆盖整场而非逐片段重置；
- 相邻独立片段数量为 N 时，恰好有 N-1 条边界台账；
- 每条边界有唯一合法策略和明确切点；
- 每条边界的两侧镜头在写提示词前已共同设计；
- 每个同场下一单元的 `opening_state` 完整复写上一单元的可见 `exit_state`，没有“同前”式省略；
- 无意外同轴近景缩放、姿势重置或未展示的道具状态跳变；
- 长画外音没有把可读嘴部持续交给模型；
- 请求时长与平台实际时长分开记录；
- 头尾余量真实存在且内容稳定；
- 若已有生成视频，已完成逐边界成片验收并标级。

任一项失败，先改 `SCENE_SHOT_LADDER`、`CLIP_BOUNDARY_LEDGER` 或片段分组，再写/改提示词。
