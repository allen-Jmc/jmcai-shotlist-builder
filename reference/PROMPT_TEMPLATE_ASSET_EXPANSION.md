# 影视级资产提示词扩展规范（即梦5 / MJ / Flux 最佳短剧资产工作流）

本规范作为 `jmcai-shotlist-builder` 的扩展参考层，用于指导角色（单人神颜/工业四视图）、场景（空镜无人）及道具（悬浮单品展示）的文生图生成。通过工程化铁律与电影摄影参数，杜绝欧美脸、AI 油腻塑料感、歪眼死鱼眼与空洞虚词，实现院线级与工业短剧级资产质感。

---

## 一、固定三大工程铁律（每次生成必须严格遵守）

1. **人种与骨相锁定**：
   - 必须显式标注：`中国男生/女生，亚洲面孔，东亚五官`。
   - **工程目的**：杜绝文生图大模型（MJ、即梦等）在默认权重下生成欧美混血感或西方骨相。
2. **皮肤去油防蜡质感**：
   - 必须显式标注：`哑光妆效/哑光皮肤质感，无油光，不泛油，皮肤通透`。
   - **工程目的**：彻底阻断 AI 常见的塑料蜡质感、过度磨皮假面脸以及大面积高光油腻感。
3. **眼部缺陷前置防御**：
   - 必须显式标注：`双眼都睁开，对称双眼`，后接具体眼神（如`眼神清冷淡淡看镜头`、`眼神温柔低垂`）。
   - **工程目的**：杜绝 AI 单眼 wink、大小眼、瞳孔斜视或非自愿闭眼。
4. **场景空镜无人律**：
   - 场景概念图默认必须为**空镜无人**，提示词结尾负面词追加：`人物，人，人脸`，防止生成人物干扰分镜调度。
5. **杜绝虚词，具体化呈现**：
   - 严禁使用“高级感”、“氛围感”、“极具美感”等空泛形容词；必须具象化为**具体物件、空间相对位置、材质经纬、磨损划痕、光线入射方向与影子长度**。

## 二、角色资产双轨规范

为了平衡“创作者快速抽卡锁定神颜”与“视频大模型（MiniMax H3 / Seedance）工业输入”的双重需求，本技能支持**双轨资产提示词**：

### 轨道 A：即梦5 / MJ 精简版单人立绘（天命神颜抽卡）

* **设计原则**：一段到底，无分段编号，无四宫格，无英文指令，无多余负面词，全部使用高密度中文。
* **固定写作顺序**：
  ```text
  画质光线 → 身份年龄（亚洲限定）→ 气质标签 → 身高体型
  → 皮肤（哑光无油光）→ 妆容唇色 → 发型（碎发层次）→ 五官眼睛（双眼睁开）→ 表情
  → 上装（面料/领型/细节）→ 内搭 → 下装 → 鞋
  → 配饰/随身道具 → 姿势+全身可见 → 镜头透视+棚拍背景 → 身材比例
  ```
* **通用空白模板**：
  ```text
  最高画质，杰作，超精细，【柔和自然光/干净棚拍光线】，一位年轻中国【男生/女生】，亚洲面孔，东亚五官，【年龄】岁，【气质关键词，2-3个】，身高【】，身形【纤细/挺拔/精瘦/健美】，【哑光妆效/哑光皮肤质感】，【冷白皮/健康小麦色/自然肤色】，皮肤通透，无油光，不泛油，【妆容：伪素颜淡妆/几乎素颜/自然淡妆，唇色】，【发型：颜色+长度+扎法+刘海+碎发】，【眉形】，【眼型】，【瞳色】眼睛，双眼都睁开，对称双眼，眼神【】，【鼻梁】，【唇形】，【表情：浅笑/清冷不笑/坏笑……】，【耳朵/脖子配饰】，穿一件【上装：颜色+面料+款式+领型+袖口+纹理细节】，内搭【】，下身【下装：颜色+版型+长度】，脚踩【鞋】，【随身道具/包/手持物】，标准【站立/放松】姿势，【手部动作】，全身可见，从头到脚都在画面内，正常透视，50mm标准镜头，干净浅灰色棚拍背景，柔和均匀漫射光，正常身材比例，【纤细/挺拔修长/健美有线条】。
  ```
* **特写肖像替换规则**：
  - 如只需头像或半身特写，将结尾“全身可见、从头到脚都在画面内、正常身材比例”替换为：`头肩肖像，面部特写，浅景深`。

### 轨道 B：工业四视图生产规范（MiniMax H3 / `<Subject N>` 专用）

* **构图框架**：严格维持 `16:9` 横版画布、无缝纯白影棚背景。
  - 左侧 1/4：正面面部颈部截切特写。
  - 右侧 3/4：水平并排三具全身等高姿态——正面躯干（面部浅灰平涂遮盖、保留头部轮廓）、完整侧身（带头、侧脸清晰）、完整背面（带头）。
* **细节融入要求**：
  - 左侧特写：全面植入三大铁律（东亚五官、哑光无油光、对称双眼、清晰下颌线与发丝层次）；
  - 右侧躯干：全面植入具体面料（珠地棉、精纺毛料、真皮做旧纹理、明线走线与下摆剪裁）。

## 四、场景提示词规范（空镜无人七步法）

### 4.1 固定写作顺序
```text
① 空间结构与朝向（几进、几层、长宽比、层高）
② 具体物件与微观布局（核心家具/道具位置、材质、新旧、磨损刻痕）
③ 光线物理路径（光源方向、色温、投影长度与漫反射）
④ 感官通觉（微尘悬浮、空气温度、湿度、冷热对流感）
⑤ 电影美学风格（导演/摄影师视点，避免套路化）
⑥ 胶片型号与色彩倾向（绑定具体胶卷与暗部偏色）
⑦ 光学镜头参数（焦段 + 光圈 + 景深）
```

### 4.2 空白模板
```text
【空间：什么地方，多大，结构，朝向】，【物件1：位置+材质+新旧+具体磨损状态】，【物件2……】，【光线：从哪来，什么颜色，怎么落，影子状态与明暗交界】，【微尘浮动/空气冷暖/寂静感】，【摄影风格，如：是枝裕和式日常凝视 / 杜可风式室内光影 / 王家卫式光影】，【胶片型号】胶片，【颗粒：细腻/中等/粗颗粒】，【色调：暗部偏什么色，高光偏什么色】，【】mm镜头，f/【】，【浅/深/极浅】景深，电影宽屏。
```

## 八、人物资产版与镜头版美学分层

人物设定图与场景图**不能共用同一段美学提示词**。两者必须分层，共用质感，分离光线。

| 层 | 人物设定图（资产版） | 场景图 / 道具 / 视频全局锁定（镜头版） |
| :--- | :--- | :--- |
| 光 | 高调平光、均匀正面漫射、低对比、无逆光、无光晕、无聚光暗角 | 按剧本动机给光：逆光、侧逆、冷暖对比、窗光或实景光源 |
| 背景 | 中性浅灰无缝背景，无场景、无道具、无虚化环境 | 实景空间，按七步法写足层次 |
| 景深 | 全身视图保持可读，不用浅景深吃掉细节 | 可用浅景深、焦外虚化 |
| **共用** | 柔焦、胶片颗粒、低对比、暗部抬起、人物肤质句（**逐字一致**） | 同左 |

**为什么必须分层**：把完整的叙事光美学直接套进人物设定图，背景会被画成虚化的户外场景，人物带上逆光光晕，四视图版式直接崩掉。人物的粉嫩通透感只来自曝光、调色、柔光与肤质——不是来自逆光。

**同步规则**：改动任一侧的肤质句、调色词或质感词时，另一侧必须同步改。两版的人物肤质句必须逐字相同，否则设定图与成片里不是同一种质感。

## 九、资产提示词负向词避坑表

以下是在**柔光高调 / 偶像剧质感**美学下实测会翻车的词。用于该美学体系时按表回避；换成写实硬调、悬疑冷调等其他美学体系时，这些词多数可以正常使用。**这是条件性经验，不是普适禁令。**

| 写了这个词 | 实际后果 | 替代写法 |
| :--- | :--- | :--- |
| 暖琥珀、米灰、暖灰、奶油白为主色调 | 画面整体发黄 | 只写「暖桃粉色调」，且必须点明是**调色**而非主体色 |
| 冷暖对比、青灰 | 背景发冷，压不住暖调 | 冷色只写一处具体元素（瓷砖、黑板、玻璃），不写全局冷暖 |
| 单独写「粉调」（不带「暖桃」、不说明是调色） | 背景偏紫 | 写「暖桃粉色调的调色」 |
| 发丝金边、逆光 | 明显光晕，头发呈橙金色高光 | 需要亮边时写「高光溢出」，不写逆光与金边 |
| 冷白、瓷白、水润唇、眼睛明亮有神 | 冷白锐利的韩系脸 | 写「白皙通透」「眼神稳定」 |
| 真实皮肤肌理 | 素颜路人脸，失去柔光感 | 写「皮肤通透、细腻光洁」 |
| 眼影、腮红、红晕、唇色、甜美美颜感 | 画出妆容，男性尤其明显 | 脸上不写任何颜色词，粉嫩感交给曝光与调色 |
| 全部视图清晰对焦 | 画面过锐，与柔焦冲突 | 只写「五官清楚、细节柔和」 |
| 人物区域提亮、四边压暗 | 出现聚光与暗角 | 写「均匀漫射光，无暗角」 |
| 宽度不超过四分之一、肩部下缘淡出 | 特写缩成飘在半空的小头像 | 写「左侧特写占满整个画面高度，头顶接近上缘、下缘到画面底边」 |
| 空气感强、柔光镜拍摄、极低对比、暗部与头发偏灰 | 整体过曝发白、蒙灰雾，深肤色与深色衣物被压成奶白灰 | 写「低对比，暗部轻微抬起」；深肤色角色必须单独校准 |
| 人物某侧轮廓的暖色柔光 | 变相逆光，发丝一侧发橙发亮 | 只写「正面柔和漫射光」 |
| 正常曝光、面部保留明暗层次 | 变成普通摄影，失去高调柔光感 | 写「高调明亮曝光，高光不过曝」 |

## 十、正面全身视图的遮脸变体

四视图右侧的正面全身视图必须阻断「H3 从这里取脸」。默认做法是**浅灰平涂遮脸**，无头截切作为 fallback。二者不得混用。

### 10.1 默认：浅灰平涂遮脸

保留头部轮廓与完整头身比例，面部用浅灰色平涂完全遮盖，不显示五官。

**为什么默认用平涂而不是切头**：整张四视图是作为**一个** `<Subject N>` 交给 H3 的，模型必须从中读到完整人体比例才能生成全身镜头。切掉头会丢失头身比与头顶高度两个关键量，三个视图也无法做头顶等高对齐——等于用文字去补视觉信息的缺失。

**提示词必写句**（逐字保留）：

```text
正面全身视图的面部用浅灰色平涂完全遮盖，不显示五官；保留完整头部轮廓与头身比例；平涂为无材质、无明暗渐变、无边缘线、无绑带的纯色块，不是面罩、绷带、头盔或头套；正侧面视图保留清晰侧脸，不得遮盖。
```

**回传检查 5 项**：

- [ ] 只遮了正面全身视图，正侧面侧脸完整清晰（误遮 → 修图恢复或重跑）；
- [ ] 平涂未变成面罩、绷带、头套，无绑带与边缘线；
- [ ] 平涂上未被补出眼睛、鼻子或嘴；
- [ ] 正面全身视图保留完整头部轮廓，头身比与侧身、背面一致；
- [ ] 三个视图头顶等高、脚底对齐。

### 10.2 Fallback：无头截切

当目标出图模型反复把平涂画成面罩/绷带/头套，或反复补出五官，且重跑两次仍不收敛时，该角色改用无头截切：在颈部干净截切，正面全身视图不出现头部，侧身与背面保留完整头部。

切到 fallback 后：

- 提示词改为 `正面全身视图在颈部干净截切，不出现头部；正侧面与背面保留完整头部`；
- 头顶等高对齐只对侧身与背面两个视图成立，正面视图改用「颈部截切位对齐同一解剖高度」；
- 必须在面向操作员的资产清单里注明该角色用的是哪一种变体，便于后续单元沿用同一约定。

### 10.3 不变项

无论用哪种变体，人物设定图的 `identity + wardrobe reference` 定性不变；映射给 H3 时整张四视图仍只作为一个 `<Subject N>`，不拆成四个参考单元。

## 十一、换装多套设定图

同一角色在剧本中换了服装（隔天、换工作服、变装、受伤后换衣），**每套服装各出一张设定图**，不复用同一张图硬改。

- 脸、发型、体型字段**逐字不变**，只改服装字段。
- 编号规则：第一套 `①`，换装版 `①-B`、`①-C`……；多角色时角色序号与换装后缀不混用。
- 在人物锁定卡的 `outfit_variants` 里写明每套服装适用于哪些单元（卡的定义见 14.3），第 3 阶段分段完成后补写到具体 `H3-XXX`。
- 换装图的文件名必须可区分：`character_<name>_fourview_outfitB.png`，不得与基础版同名。

---

## 十二、正反打双场景图

两人对话戏若采用正反打，必须出**两张场景图**，不能一张场景图正反打硬切：

- **场景 A**：从甲方一侧看向乙方所在区域 —— 用来拍乙方。
- **场景 B**：从乙方一侧看向甲方所在区域 —— 用来拍甲方。

生成顺序与一致性：

1. 先出 A，用户回传后再以 A 为参考图出 B，保证材质、颜色、陈设、磨损细节一致。
2. **左右镜像**：A 里位于画面左侧的门窗、光源与主要陈设，在 B 里写到画面右侧；反之亦然。
3. 两张都必须是空镜无人，并各自写明主光从画面哪一侧来。
4. 回传检查：A、B 是否为同一个地方（同一套家具、同一处磨损、同一光位关系）；不一致时优先局部修图，不重跑整张。

映射给 H3 时，两张场景图各自独立编号为 `<Subject N>`，并在提示词里写清「拍甲方用场景 B、拍乙方用场景 A」，禁止在同一镜头内混用两张环境图。

## 十三、出图前自检清单（Pre-flight Asset Lint）

在最终交付文生图提示词之前，逐项对照核检：

- [ ] **人种锁定**：是否明确包含“中国男生/女生，亚洲面孔，东亚五官”？
- [ ] **皮肤控油**：是否包含“哑光妆效/哑光皮肤质感，无油光，不泛油”？
- [ ] **眼态校准**：是否包含“双眼都睁开，对称双眼”？
- [ ] **结构合规**：立绘是否一段到底（无分段序号、无英文字段、无多余负面词）？
- [ ] **场景纯净**：场景图是否严格“空镜无人”，并在负面词排除人像？
- [ ] **质感具象**：是否用具体面料、磨损、划痕代替了“高级感/氛围感”等空洞形容词？
- [ ] **影调指定**：是否显式指明了具体胶片型号（如柯达 Vision3、富士 Pro 400H）与光影入射角？

## 十四、资产回传验收与人物锁定卡

第十三节查的是**提示词写得对不对**；这一节查的是**用户传回来的图能不能用**。两者不能互相替代：提示词合规的图一样可能版式崩、左右配饰反、背景变成实景。

### 14.1 验收清单

用户回传设定图、场景图或道具图后，逐项核对。**按项目已批准的美学口径判断，不要套用别的项目的口径。**

**版式（四视图）**

- [ ] 左侧面部特写约占三分之一宽、**占满整个画面高度**（头顶接近上缘、下缘到底边），脸大而清楚——不是缩成飘在半空的小头像；
- [ ] 右侧三个全身视图约占画面高度九成、间距均匀、**脚底踩同一条水平线**、**三个头顶等高**（正面视图不豁免）；
- [ ] 无接缝、无独立底色块、无墙地交界线、无文字、无水印、无边框分格线。

**遮脸**

- [ ] 只遮正面全身视图；正侧面侧脸完整清晰；
- [ ] 平涂未变成面罩、绷带、头套，无绑带与边缘线，未被补出眼鼻嘴；
- [ ] 正面视图保留完整头部轮廓与头身比（用 headless fallback 时改为核对颈部截切位是否对齐）。

**背景与光**

- [ ] 背景是同一块无缝纯色（或项目指定的中性背景），**无场景、无道具、无虚化环境**；
- [ ] 整体平光、低对比、柔焦但五官清楚；
- [ ] 无逆光光晕、无发丝橙金高光、无聚光、无暗角——这几项是"把场景美学误套进人物图"的典型症状，出现就回查是否用错了美学版本。

**脸**

- [ ] 没有越过项目已批准的妆容口径（若项目规定不化妆，则不得出现眼影、腮红、彩色唇）；
- [ ] 肤质与该项目的肤质句一致，未变成冷白锐利或粗糙素颜；
- [ ] 若出现不该有的妆容，先查人物字段里有没有妆容或脸部颜色词，改字段再重跑，不要靠负向词硬压。

**手**

- [ ] 双手空着，未凭空多出道具；
- [ ] 手里多出道具时，回查「身份」字段是不是写成了"正在做的事"（如"来店里买奶茶的顾客"），改成纯身份即可。

**一致性**

- [ ] 特写的脸与侧脸是同一人；
- [ ] 发型、发色、服装颜色、配饰及其**左右位置**在特写与三视图中一致。

### 14.2 判定：重跑还是收下

- **建议重跑**：特写与侧脸明显不是同一人；背景变成实景；人物成了剪影或严重变形；三视图比例失衡到无法用作参考。
- **修图解决**：侧脸被误遮、局部文字或污点、单处配饰错位。
- **收下并写进锁定卡**：版式正确、身份正确，只是细节需要固定下来（配饰挂在哪一侧、系带在哪打结、手表戴哪只手）。**这类不重跑**——重跑成本高且结果随机，写死反而更稳。

### 14.3 人物锁定卡

每个主要角色在资产批准后建立一张锁定卡，作为后续**所有**提示词的唯一细节依据。它放在面向操作员的资产清单里，**不进可复制提示词**。

```text
character_lock_<name>:
  face_source: 左侧面部特写（正面全身已遮脸，不得从此处取脸）
  hair: 颜色 / 长度 / 扎法 / 刘海 / 碎发走向
  wardrobe: 上装 / 下装 / 鞋（按套，对应 ①、①-B…）
  accessories: 每件 + 位于角色自身哪一侧（左/右必须写死）
  distinctive_marks: 疤痕 / 痣 / 不对称细节，及位于哪一侧
  sheet_variant: flat-grey-mask | headless
  outfit_variants: ① → 适用单元；①-B → 适用单元
  approved_version: 资产版本号或批准日期
```

使用规则：

- 锁定卡一旦建立，**后续提示词照此写死**，不再依赖"参考图里有"这种隐含前提——参考定义不保留细节状态。
- 同一角色的锁定卡**只有一张**，换装不新建卡，只在 `outfit_variants` 里加行。
- 换装、伤痕、局部改动产生新版本时，更新 `approved_version`，旧版本作废。
- 锁定卡与 `HELL_GRIND_ADAPTATION.md` 的 `BEHAVIOR_BASELINE` 分工不同：锁定卡管**外观**，行为基线管**行为**，两者都不进可复制提示词。

### 14.4 场景图与道具图的回传验收

- **场景**：是否为同一地点（同一套家具、同一处磨损、同一光位关系）；是否严格空镜无人；画面文字是否写对、是否与台词冲突；剧情必需的道具是否都在且状态正确。
- **正反打 A/B**：两张是否同一地方；A 中位于画面左侧的门窗与陈设，在 B 中是否落在画面右侧。
- **道具特写**：外观与文字是否与场景里那一件完全一致；是否为 45 度悬浮展示、纯色背景、单侧打光。
- 以上不合格时**优先局部修图**（以参考图为底图，保持构图/光线/色调/物体/文字排版不变，只改指定项），不重跑整张。
