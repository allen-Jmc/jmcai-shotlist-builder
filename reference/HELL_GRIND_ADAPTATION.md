## 增补一：资产文字与图片成对、版本可追溯

在现有资产映射行上追加，不另造重复数据库：`asset_id / exact_filename / approved_version / role / canonical_descriptor / state_variant / applicable_scenes`。

- `canonical_descriptor` 只写稳定身份、服装/道具识别点或固定空间地标；同一版本复用相同文字。当前湿度、持有人、损伤、姿态与动作属于现有状态链，不混进永久身份。
- 实际文件名、内部资产 ID、当前单元上传槽位是三件事。每次编译重新核对真实上传顺序；不能把跨项目稳定 ID 当作 H3 槽位。
- 资产只有批准后的新版本才能替代旧版。用户提供了可用资产时先接收映射，不仅因外部流程偏好就要求重做。
- 局部修改采用“本次改变什么／其余必须保留什么”的最小范围。保留原件，另存变体。服装、伤痕等已有局部编辑能力可解决时，优先局部编辑；不宣称任一模型能保证像素不变。
- 反复换脸或道具形状漂移时先查资产版本、冲突参考、引用用途和上传槽位，再改描述。必要时建议补反打场景图或关键帧；不能把错误源图反复全图加工当成唯一办法。

## 增补二：行为基线与当场策略分开

给主要复现角色建立简短内部 `BEHAVIOR_BASELINE`，与现有 VOICE_BIBLE 并列：惯常身体节奏、压力触发、掩饰方式、被触发后可能改变的渠道、剧本依据。无依据的童年创伤、疾病、性格诊断、固定小动作不添加。允许标记为暂定导演解读，不把推测写成原剧本事实。

每场从基线选择能在当下姿态中执行的一项行为，写进现有 SHOT_SCORE / MICRO_PERFORMANCE_SCORE，不新增长篇字段。例如一个已经有剧本依据的“焦躁地走动”人物被要求坐着时，可用未完成的起身或短暂重心前移承接同一种行动冲动；不能为了保留习惯而擅自让他离开座位。

当原有策略遭到阻力、信息改变或关系转折时，指明 `触发 → 原策略失效 → 新的可演行动 → 声音/身体结果`。短场可能只有一次转折；不强制每段出现两到四种情绪。

听者应在听懂的那个词、看见的那个动作上反应，不必一律等对方说完；多人有不同获知时点，不同步点头、眨眼或转身。仍遵循当前时间线和注意力预算。声线身份保持原文复用，变化的是压力、气息、重音和策略，不是换一个人的声音。

## ACTING SYSTEM: shot-level execution

2026-09-07重新完整读取上列 ACTING SYSTEM 公开附件。以下是针对H3的自行编写适配，不复制其整段人物档案，也不宣称该附件已经核实为Hell Grind首发版。

表演校准不能只给行为基线或“悲伤、紧张”。对每名当前可见角色，在已有SHOT_SCORE记录：想让谁做什么、眼前阻碍与代价、当前策略动词、令策略改变的确切声/词/动作、可见行为变化、句后/切后残留、对应镜号和时间。每个策略变化至少有一处最终提示词证据；不强制每段2—4次转折。无台词的听者也有目标与行动，系统合成声则遵从剧本，不拟人化。

- 意图必须改变演法。例如“让对方继续看自己”应体现为追住对方视线、抑制失声以完成命令，而不是只加“焦急地说”。不要将这个案例变成所有角色的固定动作。
- 反应锁定角色实际获得信息的时点。听懂威胁词时可以先停下手中动作，随后改变眼线/重心；不一律等全句结束，不让所有人物同步反应。没有新信息时不凭空切换情绪。
- 矛盾要有剧本依据：外在要稳住对方，身体却泄露害怕；照顾对方的动作可以与自身疼痛并存。不得提前演出后续牺牲、遗忘或释然，不能添加创伤史解释动作。
- 视线有目标而非配额：注明从谁的脸移到哪只手/门锁/屏幕及其原因，眼先于头。不要机械添加眨眼、吞咽、眼泪和抖动。
- 强动作之后保留代价：撞击后的受伤侧、呼吸中断、握持压力或步态变化跨镜延续；不能一切镜就恢复中性状态。剧情必需的起因、过程、结果必须可见，不照搬原文“只写状态”而省略动作因果。
- 原台词逐字保留。不得迁入原文的填充词、重复、断句改词建议；声线身份锁定，变化的是本句目的、支持气息、重音和句尾。数值字速只作估时。
- 镜头给表演可读条件：近景少量变化；远景用方向、距离、姿态而不是无法辨认的嘴角。每个关键反应获得明确时间窗，不能在奔跑、对白、拉焦和多重表情同时发生时假定全部可读。

首帧是第一动作的有效瞬间，不是摆拍的“悲伤合影”，也不提前展示双方已完成的回应。先确定表演时序，在文字分镜中呈现连续行动的不同瞬间；改变机位就应在文字镜头账中有真实剪切。文字分镜应显出“触发—反应—新行动”，与中英文稿及原文同源。

校准交付附简短表演变化表，让用户能指出哪一镜体现了哪项策略。复核四问：去掉情绪形容词还有行为吗；听者仍在主动回应吗；策略转变有触发和代价吗；下一镜保留了上一镜的身体余波吗？文字审查只说明设计可执行，不宣称实际视频已达到某表演评分。

## 增补三：按证据做定点迭代（执行）

收到成片反馈或候选素材时，给受影响单元记录：`unit_id / prompt_version / asset_versions / observed_failure / evidence_time / changed_axis / change_summary / result / next_action`。没有实际素材就标为“文字风险判断”，不能写成实测结果。

每轮只改一个主要失败原因：资产、绑定、空间、动作负荷、表演、时序或剪接。修中文后同步英文及相关文字分镜；一致性必需的多处联动仍属于同一修复，不受“一行”字面限制。保留已经有效和已批准的内容，不整段无依据重写。

重复同一失败且没有新假设时，应建议简化调度、拆出复杂动作或补关键参考，保留全部剧情因果与台词；不以删剧情解决。重试次数、费用和生成范围由用户授权决定，不照搬“必须重试10–15次”。提示词更新不自动调用付费视频生成。

## 不迁入的外部处方

- 不强制每个单元用一秒静态大全景；现有导演开场与边界策略优先。
- 不在新片段重复上一段台词、追加“嗯”或口头禅来帮助模型识别镜头。
- 不用“直接从动作结果开始”跳过原剧本必要的动作过程。
- 不强制每秒眨眼/吞咽；静止可以是有目的的倾听，不能用表情配额替代表演。
- 不迁入固定3000字长提示词、FOV数值处方、年龄删除、过滤器规避、Soul/NBP专用路由或模型能力断言。
- 无背景音乐的用户要求覆盖任何外部和本地示例中的配乐；保留确有来源的对白、旁白、环境声和动作声。

## 编译优先级

当前用户约束 → 批准的剧本/镜头/资产 → 主 SKILL 的中英双稿契约 → 本层内部增补。旧表演示例中的英文标签或“台词之后堆演技说明”不得污染中文导演稿；中文始终是声线与演绎在前、原台词独行、余波归入明确后续时间窗。
