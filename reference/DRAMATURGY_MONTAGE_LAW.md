# 影视戏剧学、视觉细节与剪辑控制律 (Dramaturgy, Details & Montage)

本规约作为 `jmcai-shotlist-builder-beta` 的核心视听指导层，用于提升分镜中镜头描述的戏剧张力、肢体微反应与剪辑因果链。**“没有戏剧学，模型语法一文不值；没有可观察的物理细节，镜头就会退化为无意义的动态壁纸。”**

---

## 一、 单场戏剧成立公式 (Scene Formula)

任何一场戏，只有同时满足以下五个要素，戏剧张力才能成立：

$$\text{单场戏剧} = \text{主角欲望} + \text{阻碍} + \text{空间几何} + \text{受控视线} + \text{剪辑节奏}$$

1. **主角欲望 (Desire)**：角色在当前这几秒内**最迫切想得到的具体目标**（如：掩盖手中的老紫砂壶、逼对方退后一步、看清对方神色）。
2. **阻碍 (Obstacle)**：横亘在欲望面前的阻力（物理障碍、对手挑衅、身份规训、时间紧迫）。
3. **空间几何 (Space Geometry)**：谁站在支配机位（高位/居中/逼近），谁处于压迫退缩机位，威胁来自哪个方向，安全出口在何处。
4. **受控视线 (Controlled Gaze)**：画面每一帧必须有且仅有**一个唯一的第一视觉落点**，严禁让观众视线无所适从。
5. **剪辑节奏 (Editing Rhythm)**：每一个镜头的驻留时长、悬念停顿点与刀口切入点。

在编写任何分镜提示词前，必须能在心中用一句话回答这五点；若回答不出，说明这场戏尚未完成导演规划。

---

## 二、 单镜头三大物理细节铁律 (The Three-Detail Rule)

> **铁律：细节强化情绪，偷懒毁掉成片。**
> 每个镜头必须且只能包含三项具体的物理事实，严禁空洞形容词。

在撰写中文审稿版【镜头设计】与英文执行版 `detailed_description` 时，必须为每个镜头注入以下三大物理支柱：

### 1. 空间物理压力 (Environmental Pressure)
环境不是背景布，环境必须向角色施加物理与心理压力：
* 冷白惨淡的冰箱反光 / 暴雨冲刷下的深色湿漉沥青路面 / 头顶高频微闪的荧光灯管 / 水壶嘴喷出的滚烫白汽 / 逼仄狭窄的石柱回廊 / 玻璃幕墙上的冷酷倒影。

### 2. 身体微动作 (Physical Micro-Action on the Body)
**角色情绪只能在肉体上呈现，绝对不能停留在文字概念上**：
* 严禁写“他很愤怒/她很悲伤/他很从容”；
* 必须转化为可被摄像机捕获的肌肉与骨骼反应：
  - **紧绷/隐忍**：咬肌骤然紧绷凸起、双拳指节因用力而发白、嘴唇抿成一条薄线、眼帘微垂1/4英寸、咽喉深处艰难滚动咽口水、手指指甲抠进手心。
  - **从容/蔑视**：肩线极度松弛下沉、下颌微抬视线不眨眼平视、呼吸极其均匀缓慢、手掌稳如磐石托住物体。

### 3. 声音锚点或视觉母题 (Sound Anchor / Visual Motif)
* 贯穿全剧的感官抓手：老紫砂壶底款的暗色朱砂印、卫星电话冷硬的红绿指示灯闪烁、钟表沉重规律的秒针滴答声、长廊中清脆单调的高跟鞋踩踏回音。

## 三、 假大空废词禁用清单 (Banned Words)

以下词汇属于编剧/导演偷懒的“占位假词”，**严禁进入任何最终提示词正文**：

| 严禁使用的空洞虚词 | 为什么被禁止？ | 必须替换为的具体物理事实 |
| :--- | :--- | :--- |
| `cinematic` / `电影感` | 空泛虚词，模型无法理解 | 替换为具体焦段、景深与光质（如 `35mm, F2.0, 伦勃朗光`） |
| `beautiful lighting` / `唯美光线` | 无法指导光源物理渲染 | 替换为光源方向与色温（如 `晨光从画面右侧切过，在地面投下长影`） |
| `intense moment` / `紧张时刻` | 情绪概念词，不是画面 | 替换为演员身体与镜头动作（如 `极慢推向死死攥紧的指节`） |
| `he is sad` / `他很悲伤` | 无法演出的抽象概念 | 替换为身体微动作（如 `眼眶发红但强忍泪水，视线低垂看地面`） |
| `epic` / `史诗感` | 毫无信息的口水词 | 替换为大远景空间关系（如 `航拍大远景，百辆黑色车队双闪刺破雨幕`） |

## 四、 沃尔特·默奇剪辑六法则 (Walter Murch Rule of Six)

奥斯卡金牌剪辑大师沃尔特·默奇确立的切镜优先级。在决定“什么时候从镜头1切到镜头2”时，**上一条的权重压倒下方所有要素之和**：

1. **情绪呈现 (Emotion) —— 占比 51%**：这一个切点是否契合当前情绪的最巅峰或转折点？
2. **叙事推进 (Story) —— 占比 23%**：新镜头是否揭示了上一镜头不知道的剧情信息或人物动机？
3. **音乐节拍 (Rhythm) —— 占比 10%**：切点是否落在音效重音、台词落点或呼吸气口上？
4. **视线引导 (Eye-trace) —— 占比 7%**：观众在上一镜头的视线焦点，是否能在切到新镜头的第一毫秒顺滑接住？
5. **二维平面轴线 (2D Plane) —— 占比 5%**：是否严格遵守 180 度视线轴线，左右方向是否顺畅？
6. **三维空间物理 (3D Space) —— 占比 4%**：真实空间方位的逻辑对齐。

> **警示**：为了“追求快节奏”而胡乱切镜，在剪辑六法则中仅排第 3 位。如果切镜不能服务于“情绪与故事信息”，切出来的就是令人疲劳的碎片式短视频，而不是影视作品。

## 五、 镜头三功能律 (Three-Jobs Rule)

**每一个镜头在成片中必须且只能完成以下三个功能之一；如果一个都完不成，立刻删掉该镜头：**

1. **改变情绪**（角色内心变化、听者心理反应、或引发观众同理心震颤）；
2. **推进物理动作**（发生新的动作位移、拿出关键道具、进入新空间）；
3. **增加戏剧压力**（揭露新危机、倒计时逼近、第三者目击、空间进一步紧缩）。

> 纯粹的“唯美环境空镜”、“展示产品外观的静止镜头”，如果对剧情推进与人物心理毫无作用，一律视为废镜头。
